## 数据存储与管理课程项目

截止时间：12.30
工作参考文件：doc/

### 数据仓库大项目：
**1. 数据来源：**
1. 从以下链接下载Amazon电影和TV评价数据：http://snap.stanford.edu/data/web-Movies.html (Links to an external site.)
2. 可以结合第三方数据源或自行处理，从数据集中过滤掉TV类评价数据，找出所有电影类的评价数据。


**2. 项目要求：**
1. 针对电影及其周边信息，建立基于关系型数据仓库、基于Spark的分布式文件型数据仓库系统和图数据库的数据仓库系统，建立数据治理体系，并进行系统性能比对
2. 能够从数据来源处获取数据，并进行数据预处理
3. 建立关系型数据仓库存储模型，存储数据
4. 建立分布式文件系统存储模型，存储数据
5. 建立图数据库存储模型，存储数据
6. 在数据展现的界面上能够执行数据应用中的查询，并将在三种不同存储模型上的执行时间以数值的方式和图表的方式显示在界面
7. 建立数据治理体系
8. 数据来源：数据来源自Snap的文本文件和Amazon网站，数据包括但不限于以下信息：电影ID，评论用户ID，评论用户ProfileName，评论用户评价Helpfulness，评论用户Score，评论时间Time，评论结论Summary，评论结论Text，电影演员，电影上映时间，电影风格，电影导演，电影主演，电影演员，电影版本等信息
9. 数据应用：常见查询及统计（占总查询数目）=80%）：
   1. 按照时间进行查询及统计（例如XX年有多少电影，XX年XX月有多少电影，XX年XX季度有多少电影，周二新增多少电影等）
   2. 按照电影名称进行查询及统计（例如XX电影共有多少版本等）
    3. 按照导演进行查询及统计（例如XX导演共有多少电影等）
    4. 按照演员进行查询及统计（例如XX演员主演多少电影，XX演员参演多少电影等）
    5. 按照演员和导演的关系进行查询及统计（例如经常一起合作的演员有哪些，经常一起合作的导演和演员有哪些）
    6. 按照电影类别进行查询及统计（例如Action电影共有多少，Adventure电影共有多少等）
    7. 按照用户评价进行查询及统计（例如用户评分3分以上的电影有哪些，用户评价中有正面评价的电影有哪些等）
    8. 按照演员、导演之间的关系进行查询及统计（例如经常合作的演员有哪些；经常合作的导演和演员有哪些；如果要拍一部XXX类型的电影，最受关注（评论最多）的演员组合（2人，3人等）是什么？）
    9. 按照上述条件的组合查询和统计
    10. 溯源查询：
        1. 在过程中，我们找出了多少非电影的数据？
        2. 在ETL和数据预处理中，我们找到多少哈利波特系列的电影？这个电影有多少版本？有多少网页？哈利波特第一部我们合并了多少个不同的网页？

**3. 提交内容**
1. ETL脚本
2. 数据存储设计说明文件，包括以下内容
   1. 整体存储模式：关系型存储、分布式存储、图数据存储在本项目中是如何协同工作的，在每种类型的存储总分别存了哪些内容。
   2. 关系型存储逻辑模型：E-R图设计、数据存储模型（start schema或其他）
   3. 关系型存储物理模型：DDL，存储优化设计，Denormalization分别是如何做的
   4. 分布式文件系统存储模型（schema定义文件）及优化
   5. 图数据库存储模型及优化
   6. 数据表的test case
3. 查询和统计程序
4. 项目报告
   1. 对每种存储方式结合本项目说明各自适用于处理什么查询，针对本项目在存储优化中做了什么工作，优化前后的比较结果是怎样的
   2. 如何保证数据质量？哪些情况会影响数据质量？
   3. 数据血缘的使用场景有哪些？
5. 答辩ppt，说明组员信息和分配比例

**4. 建议平台**
1. 关系型数据库：华为openGauss
2. 分布式存储：Hive
3. 图数据存储：Neo4j
4. 计算框架：SparkSQL
